# Site Lazúli Confeitaria Artesanal

Abra o arquivo `index.html` no navegador para ver o site.

## Onde editar

Tudo que muda com frequência fica no começo do bloco `<script>` do `index.html`:

- `CONFIG`: WhatsApp, Instagram, endereço, horário e regras da loja
- `HERO`: os três bolos do banner animado
- `PRODUCTS`: cardápio (nomes, opções e preços)

As imagens ficam na pasta `img/`.

## Dica

Com a extensão Claude Code no VS Code, você pode pedir em português, por exemplo:
"troque o preço do docinho para R$ 95 o cento" ou "adicione churros ao cardápio".
